天元匯算 · 產品圖片放置說明
================================

把產品圖放進以下三個子目錄，檔名按《型號-品牌》命名，格式為 .jpg：

  images\products\gaming\     → 普通遊戲顯示卡
  images\products\compute\    → 高端算力顯示卡
  images\products\server\     → 算力伺服器

命名規則：<型號小寫>-<品牌小寫>.jpg
例：rtx5060-gigabyte.jpg、rtx5090-asus.jpg、rtxpro6000-leadtek.jpg、h200-dell.jpg

型號代碼：     rtx5060 / rtx5060ti / rtx5070 / rtx5070ti / rtx5080
              rtx5090 / rtxpro5000 / rtxpro5500 / rtxpro6000
              h100 / h200

品牌代碼：     gigabyte 技嘉 · asus 華碩 · msi 微星 · colorful 七彩虹
              leadtek 麗臺 · pny · nvidia 公版/HGX · dell · supermicro

建議規格：1200 × 900（4:3）、產品主體置中、深色或透明底均可
（卡片內為 object-fit: contain，不會被裁切）。

沒有放置圖片的條目不會出現裂圖，會自動顯示「圖片待補」占位塊，
占位塊上會印出應該使用的完整路徑，照著補圖即可。
